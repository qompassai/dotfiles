# yay config.json options

| Key                    | Type        | Options / allowed values                                                                                                                                                                                                 |
|------------------------|------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| answerclean            | String     | Predetermined answer for the “clean build” prompt; set via `--answerclean <a>` / `--noanswerclean --save`. `<a>` is one of the menu answers used in the clean dialog                                                     |
| aururl                 | String(URL)| Any valid AUR base URL. Set via `--aururl <url> --save`.                                                                                                                                                                 |
| aurrpcurl              | String(URL)| Any valid AUR RPC endpoint URL. Set via `--aurrpcurl <url> --save`.                                                                                                                                                       |
| batchinstall           | Boolean    | `true` or `false`. Controls whether yay batches installs into one pacman transaction.                                                                                                                                    |
| bottomup               | Boolean    | `true` or `false`. `true` ≈ “AUR first, then repos” (like `--bottomup --save`); `false` approximates “repos first” (like using `--topdown`).                                                                             |
| buildDir               | String(path)| Any writable directory path; supports env vars like `$XDG_CACHE_HOME`. Set via `--builddir <dir> --save`.                                                                                                               |
| cleanAfter             | Boolean    | `true` or `false`. `true` corresponds to enabling `--cleanafter --save`, removing sources after successful install.                                                                                                      |
| cleanmenu              | Boolean    | `true` or `false`. `true` corresponds to `--cleanmenu --save`, giving an interactive clean‑build menu.                                                                                                                   |
| combinedupgrade        | Boolean    | `true` or `false`. When `true`, a plain `yay` does combined repo + AUR upgrades (`-Syu` behaviour if no operation is specified).                                                                                         |
| completionrefreshtime  | Integer    | Any positive integer; conceptually “days between completion cache refreshes”, as per `--completioninterval <n> --save`.                                                                                                  |
| debug                  | Boolean    | `true` or `false`. Enables extra debug output when `true`.                                                                                                                                                               |
| devel                  | Boolean    | `true` or `false`. `true` ≈ `--devel --save`: check VCS/development packages on sysupgrade.                                                                                                                              |
| diffmenu               | Boolean    | `true` or `false`. `true` corresponds to `--diffmenu --save`, enabling a diff menu before builds.                                                                                                                        |
| doubleconfirm          | Boolean    | `true` or `false`. Adds an extra confirmation step when `true`.                                                                                                                                                          |
| editmenu               | Boolean    | `true` or `false`. `true` ≈ `--editmenu --save`, offering an edit/view menu for PKGBUILDs.                                                                                                                               |
| editor                 | String(cmd)| Any editor command (e.g. `nvim`, `vim`, `nano`). Set via `--editor <file> --save`.                                                                                                                                        |
| editorflags            | String     | Any argument string passed to the editor; split on whitespace. Set via `--editorflags <flags> --save`.                                                                                                                   |
| gitbin                 | String(cmd)| Path or name of git binary; set via `--git <file> --save`.                                                                                                                                                               |
| gitflags               | String     | Any extra git CLI args, split on whitespace. Commonly `-c key=value` overrides, transport settings, etc. Set via `--gitflags <flags> --save`.                                                                           |
| gpgbin                 | String(cmd)| Path or name of gpg binary; set via `--gpg <file> --save`.                                                                                                                                                               |
| gpgflags               | String     | Extra gpg CLI args. Set via `--gpgflags <flags> --save`.                                                                                                                                                                  |
| keepSrc                | Boolean    | `true` or `false`. `true` ≈ `--keepsrc --save`, keeping `pkg/` and `src/` after building; `false` with `--cleanafter` removes them.                                                                                      |
| makepkgbin             | String(cmd)| Path or name of `makepkg`; set via `--makepkg <file> --save`.                                                                                                                                                            |
| makepkgconf            | String(path)| Path to a `makepkg.conf`. Set via `--makepkgconf <file> --save` or `--nomakepkgconf` (to fall back to default).                                                                                                          |
| maxconcurrentdownloads | Integer    | Any positive integer, specifying max parallel downloads.                                                                                                                                                                 |
| mflags                 | String     | Any `makepkg` flags, split on whitespace; e.g. `--nocheck`, `--syncdeps`, `--clean`, etc. Set via `--mflags <flags> --save`.                                                                                            |
| pacmanbin              | String(cmd)| Path or name of pacman; set via `--pacman <file> --save`.                                                                                                                                                                |
| pacmanconf             | String(path)| Pacman configuration file path; set via `--config <file> --save`.                                                                                                                                                        |
| pgpfetch               | Boolean    | `true` or `false`. `true` ≈ `--pgpfetch --save`: prompt/import PGP keys as needed.                                                                                                                                        |
| provides               | Boolean    | `true` or `false`. `true` ≈ `--provides --save`: search and show providers for virtual dependencies.                                                                                                                    |
| ramver                 | String     | Free‑form internal/versioning string; usually left empty.                                                                                                                                                                |
| rebuild                | String     | Encodes rebuild policy. CLI forms: `--rebuild`, `--rebuildall`, `--norebuild`, `--rebuildtree --save`. Exact stored values are version‑dependent, but conceptually: always rebuild targets, all AUR, never, or whole tree. |
| redownload             | String     | Encodes redownload policy. CLI forms: `--redownload`, `--noredownload`, `--redownloadall --save`. Represents “always download targets”, “never if cached”, or “always for all AUR packages”.                             |
| removemake             | String     | Makedeps removal policy. CLI forms: `--removemake`, `--noremovemake`, `--askremovemake`, `--askyesremovemake --save`. Options correspond to always remove, never remove, ask (with different default answers).          |
| requestsplitn          | Integer    | Any positive integer; set via `--requestsplitn <n> --save`. Maximum number of packages per AUR RPC query.                                                                                                                |
| rpc                    | Boolean    | `true` or `false`. `true` uses AUR RPC (normal); `false` disables those requests.                                                                                                                                        |
| searchby               | String     | Field used when searching AUR, set via `--searchby <field> --save`. Values are field names supported by yay’s version (e.g. name, name‑desc, etc.).                                                                     |
| separatesources        | Boolean    | `true` or `false`. When `true`, keeps sources split per package instead of shared.                                                                                                                                       |
| singlelineresults      | Boolean    | `true` or `false`. `true` ≈ `--singlelineresults --save`; `false` plus no `--doublelineresults` gives multi‑line results similar to pacman.                                                                             |
| sortby                 | String     | Sort key for AUR results; set via `--sortby <field> --save`. Field names depend on yay version (for example, `votes` as in your config).                                                                                |
| sudobin                | String(cmd)| Privilege escalation command; default `sudo`, but may be set to `doas` or others via `--sudo <file> --save`.                                                                                                            |
| sudoflags              | String     | Any extra sudo flags, split on whitespace; e.g. `-E` to preserve environment. Set via `--sudoflags <flags> --save`.                                                                                                     |
| sudoloop               | Boolean    | `true` or `false`. `true` ≈ `--sudoloop --save`: keeps sudo credentials refreshed in the background.                                                                                                                    |
| timeupdate             | Boolean    | `true` or `false`. `true` ≈ `--timeupdate --save`: checks AUR pages for changes during sysupgrade and updates timestamps.                                                                                                |
| useask                 | Boolean    | `true` or `false`. `true` ≈ `--useask --save`: uses pacman’s `--ask` mechanism to resolve conflicts automatically.                                                                                                      |
| version                | String     | Yay version string, e.g. `12.5.7`. Managed by yay itself; not normally edited manually.                                                                                                                                  |
