# GPG 2.4.9 Flags Reference

This reference is tailored to **GnuPG 2.4.9-1 on Arch Linux** and cross-checks each extracted flag against the Arch `gpg(1)` man page for the GnuPG 2.4 series and the upstream GnuPG options manual.[cite:37][cite:22][cite:23]

Each dropdown gives a short explanation plus the accepted value forms for **this version** and, where useful, notes about **upstream 2.4 behavior**. Some entries in the original extracted list were parsing artifacts rather than real options, and those are called out explicitly.[cite:37][cite:23]

## Notes

- `none` means the flag is normally a boolean switch with no argument.[cite:23]
- `version-dependent` means the pasted extraction did not preserve enough context to guarantee the exact short-form meaning, or upstream behavior can vary by build options.[cite:37][cite:22]
- Long options can be placed in `~/.gnupg/gpg.conf` without the leading `--`; short options cannot.[cite:23]
