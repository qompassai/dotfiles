[1;91m[0m[1;91mName[0m

[1;94mnix daemon[0m - daemon to perform store operations on behalf of non-root clients

[1;91m[0m[1;91mSynopsis[0m

[1;94mnix daemon[0m [[3moption[0m...] 

[1;91m[0m[1;91mExamples[0m

[93m  · [0mRun the daemon:
    
    [1;94m  │ [0m[1m# nix daemon[0m

[93m  · [0mRun the daemon and listen on standard I/O instead of binding to a UNIX
    socket:
    
    [1;94m  │ [0m[1m# nix daemon --stdio[0m

[93m  · [0mRun the daemon and force all connections to be trusted:
    
    [1;94m  │ [0m[1m# nix daemon --force-trusted[0m

[93m  · [0mRun the daemon and force all connections to be untrusted:
    
    [1;94m  │ [0m[1m# nix daemon --force-untrusted[0m

[93m  · [0mRun the daemon, listen on standard I/O, and force all connections to use
    Nix's default trust:
    
    [1;94m  │ [0m[1m# nix daemon --stdio --default-trust[0m

[1;91m[0m[1;91mDescription[0m

This command runs the Nix daemon, which is a required component in multi-user
Nix installations. It runs build tasks and other operations on the Nix store on
behalf of non-root users. Usually you don't run the daemon directly; instead
it's managed by a service management framework such as [1;94msystemd[0m on Linux, or [0m
[1;94mlaunchctl[0m on Darwin.

Note that this daemon does not fork into the background.

[1;91m[0m[1;91mOptions[0m

[93m  · [0m[1;94m--default-trust[0m
    
    Use Nix's default trust.

[93m  · [0m[1;94m--force-trusted[0m
    
    Force the daemon to trust connecting clients.

[93m  · [0m[1;94m--force-untrusted[0m
    
    Force the daemon to not trust connecting clients. The connection is
    processed by the receiving daemon before forwarding commands.

[93m  · [0m[1;94m--process-ops[0m
    
    Forces the daemon to process received commands itself rather than
    forwarding the commands straight to the remote store.
    
    [1;94m  │ [0m[1m      This is useful for the `mounted-ssh://` store where some actions need to be performed on the remote end but as connected user, and not as the user of the underlying daemon on the remote end.[0m

[93m  · [0m[1;94m--stdio[0m
    
    Attach to standard I/O, instead of trying to bind to a UNIX socket.
