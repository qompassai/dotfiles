# Inochi Session `settings.json` Reference

Config file location: `$XDG_CONFIG_HOME/inochi-session/settings.json`
(typically `~/.config/inochi-session/settings.json`)

This file is auto-generated by Inochi Session on first run. All settings can be edited directly
after the file exists. Most tracker/blendshape config is stored inside your `.inp` model file,
not here.

---

## Top-Level Fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `autoStart` | boolean | `false` | Automatically start tracking on launch |
| `language` | string | `"en_US"` | UI language. See [Languages](#languages) for valid values |
| `plugins` | array | `[]` | List of plugin file paths to load from `~/.config/inochi-session/plugins/` |
| `theme` | string | `"dark"` | UI theme. Options: `"dark"`, `"light"` |
| `UIScale` | float | `1.0` | UI DPI scaling multiplier. Useful on HiDPI displays. Range: `0.5` – `3.0` |
| `virtualSpaces` | array | `[]` | List of virtual spaces (tracker groups). See [virtualSpaces](#virtualspaces) |
| `windowHeight` | integer | `720` | Initial window height in pixels |
| `windowWidth` | integer | `1280` | Initial window width in pixels |

---

## `virtualSpaces`

An array of virtual space objects. Each virtual space groups one or more trackers together.
You can have multiple virtual spaces and switch between them.

```json
"virtualSpaces": [
    {
        "name": "Default",
        "trackers": [ ... ]
    }
]
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | ✅ | Display name for the virtual space |
| `trackers` | array | ✅ | One or more tracker objects. See [Tracker Types](#tracker-types) |

---

## Tracker Types

Each object in `trackers` requires a `type` field. The remaining fields depend on the type.

### `OSF` — OpenSeeFace

Used with the OpenSeeFace facetracker binary (`facetracker.py`).

```json
{
    "type": "OSF",
    "osf_bind_ip": "0.0.0.0",
    "osf_bind_port": 11573,
    "pollingFactor": 1
}
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `osf_bind_ip` | string | `"0.0.0.0"` | IP to bind the UDP listener. `"0.0.0.0"` accepts from any address. Use `"127.0.0.1"` for local only |
| `osf_bind_port` | integer | `11573` | UDP port to listen on. Must match OpenSeeFace `--port` arg |
| `pollingFactor` | integer | `1` | Frequency multiplier for polling tracker data. Higher = more responsive, more CPU |
| `type` | string | — | Must be `"OSF"` |

**Launch OpenSeeFace to match:**
```bash
python facetracker.py --port 11573 --ip 127.0.0.1
```

---

### `VMC` — Virtual Motion Capture Protocol

Used with VTube Studio, Puppetstring, iFacialMocap, Animaze, and other VMC-compatible senders.

```json
{
    "type": "VMC",
    "port": 39540,
    "pollingFactor": 1
}
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `port` | integer | `39540` | UDP port to listen for VMC packets |
| `pollingFactor` | integer | `1` | Polling frequency multiplier |
| `type` | string | — | Must be `"VMC"` |

**Standard VMC ports:**
- `39540` — Inochi Session default, VTube Studio default
- `39539` — Animaze default sender port

---

### `VTS` — VTube Studio

Connects to VTube Studio running on a phone or PC via its plugin API.

```json
{
    "type": "VTS",
    "phoneIP": "192.168.1.100",
    "pollingFactor": 1
}
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `phoneIP` | string | — | IP address of the device running VTube Studio |
| `pollingFactor` | integer | `1` | Polling frequency multiplier |
| `type` | string | — | Must be `"VTS"` |

---

### `IFM` — iFacialMocap

Used with iFacialMocap (iOS ARKit face tracking app).

```json
{
    "type": "IFM",
    "phoneIP": "192.168.1.100",
    "pollingFactor": 1
}
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `phoneIP` | string | — | IP address of the iOS device running iFacialMocap |
| `pollingFactor` | integer | `1` | Polling frequency multiplier |
| `type` | string | — | Must be `"IFM"` |

## `plugins`

Array of strings — each string is the filename of a `.so` plugin in the plugins directory.

```json
"plugins": [
    "my-tracker-plugin.so"
]
```

Plugins are loaded from:
```
~/.config/inochi-session/plugins/
```

---

## Full Example Config

```json
{
    "autoStart": false,
    "language": "en_US",
    "plugins": [],
    "theme": "dark",
    "UIScale": 1.0,
    "virtualSpaces": [
        {
            "name": "OSF Webcam",
            "trackers": [
                {
                    "osf_bind_ip": "0.0.0.0",
                    "osf_bind_port": 11573,
                    "pollingFactor": 1,
                    "type": "OSF"
                }
            ]
        },
        {
            "name": "Phone VMC",
            "trackers": [
                {
                    "pollingFactor": 1,
                    "port": 39540,
                    "type": "VMC"
                }
            ]
        }
    ],
    "windowHeight": 720,
    "windowWidth": 1280
}
```

## Notes

- **Tracker blendshape bindings, Lua expressions, dampen values, and parameter mappings are NOT
  stored here.** They are saved inside your `.inp` puppet file via **Save to File** in the GUI.
- `pollingFactor: 1` is correct for nearly all use cases. Only increase if tracking feels laggy
  and CPU headroom is available.
- On Wayland/Hyprland, set `UIScale` to match your monitor's `hyprctl monitors` scale value to
  avoid blurry UI.
- The `plugins/` directory is scanned at startup — drop `.so` files there before launching.
