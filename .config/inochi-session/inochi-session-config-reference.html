Inochi Session settings.json Reference

Location: $XDG_CONFIG_HOME/inochi-session/settings.json  ·  Auto-generated on first run  ·  v0.8.x

Top-Level Fields 8 fields

All keys in the root JSON object. Fields are listed alphabetically.

FieldTypeDefaultDescription
autoStart boolean false Automatically begin tracking when Session launches
language string "en_US" UI language locale code. See the Languages section below
plugins array [] List of .so plugin filenames to load from the plugins/ directory
theme string "dark" UI color theme. Options: "dark" or "light"
UIScale float 1.0 DPI scaling multiplier for the UI. Range: 0.5 – 3.0. Match to your Hyprland monitor scale
virtualSpaces array [] List of virtual space objects. Each groups one or more trackers. See Virtual Spaces below
windowHeight integer 720 Initial window height in pixels
windowWidth integer 1280 Initial window width in pixels
Virtual Spaces object schema

An array of virtual space objects. Each space groups trackers and can be switched between at runtime.

FieldTypeRequiredDescription
name string ✓ required Display name shown in the GUI switcher
trackers array ✓ required Array of tracker objects. Each must include a type field 
"virtualSpaces": [
  {
    "name": "Default",
    "trackers": [ /* tracker objects — see Tracker Types */ ]
  }
]
Tracker Types 4 types

Each tracker object requires a type field. Remaining fields depend on the type. All trackers share pollingFactor.

OSF  OpenSeeFace

Webcam face tracking via the facetracker.py script. Fully native on Linux.

{
  "type":          "OSF",
  "osf_bind_ip":   "0.0.0.0",
  "osf_bind_port": 11573,
  "pollingFactor": 1
}
FieldTypeDefaultDescription
osf_bind_ipstring"0.0.0.0"UDP listener IP. "0.0.0.0" = any interface. Use "127.0.0.1" for local only
osf_bind_portinteger11573UDP port — must match OpenSeeFace --port argument
pollingFactorinteger1Polling frequency multiplier. Higher = more responsive, more CPU usage
typestring—Must be "OSF"
Launch command:
python facetracker.py --port 11573 --ip 127.0.0.1
VMC  Virtual Motion Capture Protocol

Receives VMC-format OSC packets. Compatible with VTube Studio, Puppetstring, iFacialMocap, and Animaze.

{
  "type":          "VMC",
  "pollingFactor": 1,
  "port":          39540
}
FieldTypeDefaultDescription
pollingFactorinteger1Polling frequency multiplier
portinteger39540UDP port for incoming VMC packets
typestring—Must be "VMC"
Common VMC ports:
39540 — Inochi Session default & VTube Studio default
39539 — Animaze default sender port
VTS  VTube Studio

Direct connection to VTube Studio's plugin API running on a phone or PC.

{
  "type":          "VTS",
  "phoneIP":       "192.168.1.100",
  "pollingFactor": 1
}
FieldTypeDefaultDescription
phoneIPstring—IP address of the device running VTube Studio
pollingFactorinteger1Polling frequency multiplier
typestring—Must be "VTS"

Plugins array of strings

Array of .so plugin filenames to load at startup. Drop files into the plugins directory before launching.

"plugins": [
  "my-tracker-plugin.so",
  "another-plugin.so"
]
Plugin directory:
~/.config/inochi-session/plugins/

The directory is scanned once at startup — restart Session after adding new plugins.
Full Example Config copy-paste ready

A complete settings.json with two virtual spaces — OSF webcam and VMC phone.

{
  "autoStart":     false,
  "language":      "en_US",
  "plugins":       [],
  "theme":         "dark",
  "UIScale":       1.0,
  "virtualSpaces": [

      "name": "OSF Webcam",

          "osf_bind_ip":   "0.0.0.0",

      "trackers": [
        {
          "pollingFactor": 1,
          "port":          39540,
          "type":          "VMC"
        }
      ]
    }
  ],
  "windowHeight":  720,
  "windowWidth":   1280
}
Notes & Gotchas 4 notes
Blendshape bindings are NOT stored here.
Tracker blendshape bindings, Lua expressions, dampen values, and parameter mappings are saved inside your .inp puppet file via Save to File in the GUI.
pollingFactor
1 is correct for almost all setups. Only increase if tracking feels laggy and you have spare CPU headroom.
Hyprland / HiDPI
Set UIScale to match your monitor's scale value from hyprctl monitors to avoid a blurry UI.
Plugin loading
The plugins/ directory is scanned once at startup — drop .so files there before launching Session.
