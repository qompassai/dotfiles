When you are done you can run the following command to start InspIRCd:

	/usr/bin/inspircd

If you have installed from an official package you may need to prefix this
command with `sudo -g insert-group-here -u insert-user-here` to run as the correct group/user.

You can also use one of the helper scripts in `/usr/lib/inspircd`.
